Configuración de Credenciales

Personaliza el texto de cabecera y el volumen de impresión. Opcionalmente, carga una lista CSV para emitir credenciales completas con datos de alumnos sin perder el QR correlativo único.

📁 Hacer clic para seleccionar archivo .csv
El archivo debe usar comas (,) o punto y coma (;) e incluir columnas llamadas:
alumno, curso, dni (en minúsculas o mayúsculas).
